# Local Mart

Local Mart is a Hyperlocal Small Business Product Listing and Order Portal developed using Python, Django, Django REST Framework and MongoDB.

## Features

- User Registration and Login
- Secure Login Authentication
- Product Listing
- Product Search
- Product Categories
- Shopping Cart
- Checkout System
- Order History
- Stock Management
- Product Image Upload
- Shop Owner Dashboard (Django Admin)
- REST API using Django REST Framework
- MongoDB Integration for Products, Orders and Cart

## Project Description

Local Mart is a Hyperlocal E-Commerce web application that helps local shop owners showcase and manage their products online. Customers can browse products, search for items, add products to their cart, place orders and track their order history. The project also demonstrates REST API development using Django REST Framework and MongoDB integration for storing product, cart and order data.

## How to Run

### Step 1: Clone the Repository

bash
git clone <repository-url>


### Step 2: Open the Project Folder

bash
cd localmart


### Step 3: Install Required Packages

bash
pip install -r requirements.txt


### Step 4: Run Database Migrations

bash
python manage.py migrate


### Step 5: Start MongoDB

Make sure MongoDB is running before starting the project.

### Step 6: Run the Django Server

bash
python manage.py runserver


### Step 7: Open the Project

Open your browser and visit:


http://127.0.0.1:8000/
